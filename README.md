## 📋 项目简介
CloudX是一个轻量、精简的音乐下载器。
- **以用户为主导**：开源免费，支持多项特性，精准解决用户需求。
- **注重隐私**：通过官方接口进行下载，无任何第三方服务器参与。
- **兼容性强**：全面支持常见的编码类型，满足不同设备的兼容性需求。
- **满足不同需求**：支持自定义下载路径，支持自定义歌曲文件命名规则。
- **一步到位**：直接下载`.m4a`、`.flac`歌曲文件，歌曲元数据自动导入，免去转换格式的麻烦与困扰。
- **功能全面**：无论是单曲、歌单还是专辑，均支持解析下载，并支持同步下载`.lrc`格式歌词文件（支持下载歌词翻译、罗马音）。

## 📂 本地下载管理

- 搜索、歌单和专辑的歌曲卡片会标明“已下载”，重复下载不额外弹窗，也不会被自动拦截。
- 多选时可点击顶部操作栏的“取消选择已下载”图标（长按显示说明），只取消当前选中的已下载歌曲。
- 已完成页面可选择仅移除记录，或确认删除本地歌曲文件；有明确关联的歌词可一并删除。
- 下载详情按歌曲、下载记录和本地文件分组，展示音质、文件名、格式、大小、时长、码率、保存位置等信息，支持滚动查看和复制全部。采样率、位深等参数按系统和文件支持情况显示；无法确认的信息不会推测填充。
- 清空完成记录不会删除文件或清除已下载标记。同一首歌有多个副本时，只要仍有有效副本，就保留标记。
- 文件索引仅保存在本机。旧记录会尝试关联原下载目录中的文件，无法确认的记录不会用于文件删除；目录权限失效与文件已删除会分别显示。可在已完成页面刷新文件状态。

## ⏬ 下载任务控制与进度

- 设置中的“同时下载歌曲数”独立控制同时执行的歌曲任务，默认 **2 首**，可选 1～4 首，空位自动补入排队任务。调高立即补充任务；调低等待已有任务结束，不强行中断。
- 原“并发下载数”更名为“单曲分块并发数”，未设置时默认 **2**，仍支持最多 8 个分块；已有手动配置和任务参数不会被重置。两种并发叠加会增加连接数及资源占用。原生 MP3 转码串行执行（显示“等待转码”），保存文件继续使用互斥保护，避免同名文件冲突。
- 通知使用固定标题统一汇总，每秒至多刷新一次（内容不变不刷新），显示进行中、排队、本次完成数量和总下载速度；展开后按固定顺序显示各首歌曲的处理阶段，不再由各任务交替覆盖歌曲标题。
- 顶部支持“全部暂停”和“全部继续”（仅继续已暂停任务）；长按任务或在更多菜单选择“多选任务”。多选与歌曲列表一致：选中卡片高亮、不显示复选框，顶部提供关闭、全选和反选；右侧“所选任务操作”菜单可暂停、继续或取消所选任务。关闭多选只清空选择，不会取消下载。失败任务仍可单独或全部重试，沿用任务原来的音质、目录和下载规则。
- “排队中”和实际执行中的任务分别显示。暂停保留可用断点；取消需确认，等待下载停止后只清理对应缓存、封面、断点和转码临时文件，不删除已保存的歌曲或歌词。保存提交已经完成的任务仍会保留在已完成列表。
- 网络阶段展示实际已下载字节、总大小、速度和网络下载预计剩余时间；多分块累计计量，断点已有字节不计入本次速度。总大小未知或网络停滞时，不伪造百分比或剩余时间。
- 下载、检查音频、转码、写入标签和保存文件分阶段展示。转码使用自己的进度，其余无法测量的处理阶段显示不确定进度，不沿用网络 ETA。

## 🔄 检查更新

- 每次冷启动会通过 [Guang233/CloudX 的 GitHub Releases](https://github.com/Guang233/CloudX/releases/latest) 检查最新正式版；旋转屏幕、切换应用内页面不会重复检查，草稿和预发布版不在自动更新范围内。
- 有新版本时展示版本号和更新说明，可选择“前往 GitHub”“稍后”或“此版本不再提示”。跳过的版本保存在本机，不影响后续新版本的提醒。
- 点击“设置 → 应用版本”可手动检查，包括此前跳过的版本。启动检查遇到网络错误会保持静默，手动检查会明确提示错误。
- 通过版本号进行数值比较，本地 Git 哈希后缀不视为新旧版本差异。GitHub Actions 的版本标签构建会将标签版本写入 APK，避免安装后反复提示同一版本；本地开发构建仍使用 `app/build.gradle.kts` 中的开发版本号。

## 🤔 常见问题
**使用网页端登录为什么登陆不上？** [#35
](https://github.com/Guang233/CloudX/issues/35)

wyy网页端的风控非常容易触发，建议通过另外两个方式（手机验证码和cookie登录）登入。

**为什么有些多艺术家的歌曲会无法下载？** [#46
](https://github.com/Guang233/CloudX/issues/46)

在安卓系统中，文件名的长度是有限制的。安卓文件系统支持的最大文件名长度为255个字节。部分歌曲因艺术家过多，导致超出了系统的255字节上限，建议前往文件名设置删除艺术家的正则，以缩短文件名。
